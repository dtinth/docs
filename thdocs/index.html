Internals

  • Architecture Decision Records
    • thdocs is a CLI wrapper that exposes MyST/Sphinx authoring directly
    • thdocs’s theme CSS is independent; @apiref/shell is a visual reference
    • Sphinx is invoked with a conf.py shipped inside the thdocs package
    • Contents sidebar uses Lit component with JSON tree data, not Sphinx’s native toctree markup
    • Use Sphinx’s built-in client-side search instead of Pagefind
