# grist-kit

A CLI and type-safe client library for [Grist](https://www.getgrist.com), written in TypeScript. It provides:

- An agent-friendly [CLI](cli.md) for interacting with Grist documents.
- A [command-line tool to generate type definitions](library/generate.md) from a Grist table schema, along with a [type-safe client](library/client.md) for programmatically querying and manipulating Grist documents.
