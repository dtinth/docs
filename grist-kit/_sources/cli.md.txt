# CLI

grist-kit provides a command-line interface for working with Grist documents — [listing tables](cli/tables.md), [fetching records, and running SQL queries](cli/fetching.md) — without writing code or making manual API calls. This makes it useful for both humans and AI agents that need to inspect or manipulate Grist data directly from the shell.
